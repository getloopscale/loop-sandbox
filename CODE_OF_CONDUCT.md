# Code of Conduct

LoopSandbox follows the
[CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).
It applies to the repository, the issue tracker, pull requests and any other space where the
project is discussed.

To report a violation, write to admin@getloopscale.com. Reports are read by the project
maintainers listed in [MAINTAINERS.md](MAINTAINERS.md) and are kept confidential.
